CLAIM DISCIPLINE
----------------
A presenter electron never records a fabric execution event and never carries a fabric verdict.
Its event vocabulary is closed:
  GENESIS CLONE_GENESIS FORK SNAPSHOT PRESENTATION PRESENTATION_FAILED
  SUSPEND RESUME RETIRE RESTORE
`vecctl presenter-audit` rejects any ledger that steps outside it. tools/verify_package.py and
host/Verify-JA21Browser.ps1 both fail if the presenter source gains the ability to write a
fabric verdict.

Strict four-node execution remains the promotion gate and remains fail-closed. It is not
reachable in this package and is reported BLOCKED (exit 3), not relaxed.

CROSS-IMPLEMENTATION CONFORMANCE
--------------------------------
The C# presenter and the Python control plane must produce byte-identical canonical JSON.
substrate/evidence/presenter/CANONICAL_VECTORS.json carries 7 golden vectors generated by the
control plane, covering key ordering, control-character escapes, non-BMP text, nesting, empty
objects and a full electron shape. The presenter verifies itself against that file at startup
and refuses to seal anything if it disagrees.
