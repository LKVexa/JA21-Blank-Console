# JA21 JA Training and Evaluation Language Suite 1.0.0

A standalone, air-gap-safe technical and educational edition of the JA Training and Evaluation Language corpus.

## At a glance

- 10,000 normalized technical records
- 32 training and evaluation features
- 1,000 source-faithful `.jate` programs
- 100 programs per proficiency level
- Exact one-tenth validation-class distribution
- 22-chapter technical textbook
- Curriculum, workbook, instructor guide, grammar, compiler/runtime contracts, conformance framework, offline tools, and source preservation

## Language boundary

This suite models training and evaluation source, semantic, compiler, runtime, R12, and MCRT evidence. No native JA Training compiler or runtime was supplied, so modeled outcomes are not represented as native execution results.

## Start here

1. Read `SUITE_CATALOG.md`.
2. Read `catalogs/TRAINING_EVALUATION_ARCHITECTURE.md`.
3. Browse `catalogs/FEATURE_ATLAS.md`.
4. Open the textbook and curriculum.
5. Run `tools/validate_suite.py` in an offline Python environment.
