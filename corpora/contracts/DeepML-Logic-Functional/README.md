## Three principal products

### 1. Technical corpus

The complete 10,000-record evidence corpus is normalized into one compressed JSONL file and twenty 500-record shards. Every source hash is rechecked. A schema, guide, index, feature matrix, and diagnostic catalog support offline navigation.

### 2. 1,000-script example pack

The curated pack contains 750 positive, 185 negative, and all 65 certification programs. Files are grouped by foundations, functional programming, logic, proofs, systems, compiler transformations, diagnostics, and certification.

### 3. Textbook

The 22-chapter textbook moves from syntax and pure functions through logic, theorem evidence, planning, JA21 integration, compiler transformations, R12/MCRT lowering, diagnostics, certification, and an air-gapped capstone.

## Claim boundary

The source attachment did not include a native DeepML Logic/Functional compiler or runtime executable. This release validates structure, hashes, coverage, and publication integrity. Modeled compiler/runtime fields and expected results are preserved as corpus evidence, not misrepresented as native execution.
