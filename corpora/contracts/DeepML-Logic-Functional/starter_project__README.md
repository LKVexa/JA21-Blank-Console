# Starter Project

Use `src/main.deepml` as the capstone seed. Extend it with:

1. An algebraic domain model.
2. A total recursive function.
3. A knowledge base with at least four rules.
4. A bounded inference strategy.
5. A theorem and proof term.
6. One proof-carrying optimization.
7. A certification declaration.
8. A local evidence report containing source and semantic hashes.

Keep `policy no_network` and declare any additional effects explicitly.
