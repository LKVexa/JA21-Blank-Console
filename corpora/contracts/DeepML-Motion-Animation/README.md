
# JA21 DeepML Motion/Animation Language Suite 1.0.0

A standalone, publication-grade suite for the **DeepML Motion 0.3** portion of JA21.

## Primary deliverables

- **Technical corpus:** 10,000 normalized records, twenty navigable shards, schema, full index, topic matrix, diagnostics, and preserved coupling evidence.
- **1,000-script example pack:** source-faithful `.deepml` programs covering all 45 topics, all six tiers, all three classes, and every certification holdout.
- **Technical textbook:** 22 chapters with corpus-derived programs, laboratories, review questions, evidence checklists, and a standalone motion-toolchain capstone.

## Full suite

The release also includes a twelve-week curriculum, student workbook, instructor guide, topic atlas, grammar, language specification, compiler and runtime contracts, semantic operators, R12/MCRT schema, conformance cases, starter project, reconstructed source assets, offline inspection and validation tools, release notes, governance charter, manifests, and validation evidence.

## Start here

1. Read `SUITE_CATALOG.md`.
2. Open `textbook/JA21_DEEPML_MOTION_ANIMATION_LANGUAGE_TEXTBOOK.md`.
3. Browse `catalogs/SCRIPT_CATALOG.csv` and `script_pack_1000/`.
4. Inspect `corpus/technical/TECHNICAL_CORPUS_GUIDE.md`.
5. Run `python tools/validate_suite.py` from the suite root.

## Evidence boundary

The suite validates structure, source hashes, policies, catalogs, coverage, and package integrity. No native DeepML Motion compiler/runtime executable was included, so native parsing, solving, playback, rendering, and replay are not claimed.
