
# Starter Project

1. Parse `main.deepml` under the DeepML Motion 0.3 grammar.
2. Resolve the skeleton, joints, pose, clip, channels, keys, and state machine.
3. Verify acyclic hierarchy, target validity, key ordering, duration, and transition semantics.
4. Enforce deterministic and no-network policy.
5. Emit AST, semantic hash, R12, and MCRT evidence.
6. Execute only through a conforming runtime and record motion-state or tolerance evidence.

The project is intentionally small enough to serve as the first end-to-end compiler/runtime milestone.
