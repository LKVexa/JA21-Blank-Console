
# Starter Project

1. Parse `main.deepml` under the DeepML Specialized 0.3 grammar.
2. Resolve the domain, units, schema, tensor, operator, adapter, graph, and package.
3. Verify dimensional compatibility, local dataset policy, deterministic operator identity, and declaration-only actuation.
4. Enforce deterministic and no-network policy.
5. Emit AST, semantic hash, R12, and MCRT evidence.
6. Execute only through a conforming local runtime and record validation, replay, uncertainty, and limitations.

The project is intentionally small enough to serve as the first end-to-end compiler/runtime milestone.
