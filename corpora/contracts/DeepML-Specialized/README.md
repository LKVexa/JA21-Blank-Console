
# JA21 DeepML Specialized Language Suite 1.0.0

A standalone, publication-grade suite for the **DeepML Specialized 0.3** portion of JA21.

## Primary deliverables

- **Technical corpus:** 10,000 normalized records, twenty navigable shards, schema, full index, topic matrix, diagnostics, and preserved coupling evidence.
- **1,000-script example pack:** source-faithful `.deepml` programs covering all 42 topics, all six tiers, and positive, diagnostic, and certification roles.
- **Technical textbook:** 22 chapters with corpus-derived programs, laboratories, review questions, evidence checklists, and a standalone specialized-toolchain capstone.

## Full suite

The release also includes a twelve-week curriculum, student workbook, instructor guide, reading paths, domain architecture map, topic atlas, grammar, language profile, compiler and runtime contracts, semantic operators, R12/MCRT schema, conformance assets, starter project, reconstructed source assets, offline inspection and validation tools, a publication design system, release notes, governance charter, manifests, and validation evidence.

## Start here

1. Read `SUITE_CATALOG.md`.
2. Open `textbook/JA21_DEEPML_SPECIALIZED_LANGUAGE_TEXTBOOK.md`.
3. Choose a path in `catalogs/READING_PATHS.md`.
4. Browse `catalogs/SCRIPT_CATALOG.csv` and `script_pack_1000/`.
5. Inspect `corpus/technical/TECHNICAL_CORPUS_GUIDE.md`.
6. Run `python tools/validate_suite.py` from the suite root.

## Evidence boundary

The suite validates structure, source hashes, policies, catalogs, coverage, and package integrity. No native DeepML Specialized compiler/runtime executable was included, so native parsing, domain execution, target lowering, graphics rendering, financial calculation, robotic actuation, simulation, and replay are not claimed.
