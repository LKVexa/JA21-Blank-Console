
# Runtime Contract

A conforming runtime admits only compiler-approved artifacts with compatible language, policy, capability, hash, domain, calibration, and target profiles. It must enforce deterministic local execution, forbid undeclared network and unknown-code access, preserve provenance, expose bounded replay traces, and keep declaration-only robotic or market actions from becoming external commands.

Runtime validation is responsible for dynamic constraints, calibration ranges, causal step order, output hashes, replay identity, and tolerance-based equivalence where exact identity is not the contract.
