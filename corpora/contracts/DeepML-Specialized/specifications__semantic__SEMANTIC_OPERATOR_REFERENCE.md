
# Semantic Operator Reference

The machine-readable registry in `operators.json` is normative source material. This publication groups its operators into six families:

1. Domain declarations: schemas, units, tensors, metadata, packages, and adapters.
2. Domain operations: finance, science, graphics, robotics, and simulation operators.
3. Cross-domain reasoning: inference, sensor fusion, risk-physics coupling, and multidomain graphs.
4. Validation: units, constraints, calibration, causality, hashes, network, and authority.
5. Optimization: propagation, simplification, specialization, kernel selection, sparse planning, and folding.
6. Lowering: target representation, R12 relation, MCRT record, provenance, and replay identity.
