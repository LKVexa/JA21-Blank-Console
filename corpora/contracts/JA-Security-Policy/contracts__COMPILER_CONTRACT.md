# JA Security Compiler Contract

A conforming compiler should parse without host execution; produce stable source spans and typed AST nodes; resolve identity, role, group, resource, scope, and rule names; infer effects and capabilities; establish deterministic conflict precedence; verify attenuation, revocation, expiry, approval, redaction, and sandbox obligations; create and check proof obligations; lower accepted policy to stable R12 records; preserve diagnostics and provenance during optimization; and clearly label modeled versus native evidence.
