# JA21 DeepML Kernel Language Suite 1.0.0

> **A deterministic, teachable, audit-oriented kernel programming suite for the JA21 language family.**

`DeepML Kernel Language` (`.dmk`) is presented here as a complete sub-suite rather than an isolated corpus. The release joins executable teaching examples, technical records, language contracts, provenance models, conformance guidance, and course material under one compact, offline-first package.

## Validation boundary

The uploaded corpus specifies expected compile/runtime outcomes, but no native DeepML Kernel compiler or JA21 device runtime was supplied. This release therefore validates record integrity, script structure, declared policies, catalogs, path safety, provenance fields, and package consistency. It does **not** claim native compilation, device execution, benchmark results, or physical validation of the Smithson 8S model.

## Start here

1. Read [`SUITE_CATALOG.md`](SUITE_CATALOG.md).
2. Open [`textbook/JA21_DEEPML_KERNEL_LANGUAGE_TEXTBOOK.md`](textbook/JA21_DEEPML_KERNEL_LANGUAGE_TEXTBOOK.md).
3. Copy [`starter/hello_kernel.dmk`](starter/hello_kernel.dmk) into a test workspace.
4. Search the examples through `catalogs/SCRIPT_CATALOG.csv`.
5. Run `python tools/validate_suite.py` from the suite root.
