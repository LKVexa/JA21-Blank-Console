# JA21 JA Portal Scene Language Suite

**Version:** 1.0.0  
**Language:** `ja.portal.scene`  
**Primary profile:** `PORTAL_SCENE_R12`

A standalone, air-gap-safe JA21 language publication for deterministic scenes, entities, components, assets, events, animation, UI, physics, portals, terrain, persistence, compiler lowering, replay, and certification.

## Primary products

- 10,000-record normalized technical corpus with twenty research shards.
- 1,000 source-faithful `.ja` programs: 700 positive, 175 diagnostic, and all 125 certification holdouts.
- Twenty-two-chapter technical textbook (17,812 words).
- Twelve-week curriculum, workbook, instructor guide, and starter project.
- Grammar, language profile, compiler/runtime contracts, semantic registry, R12/MCRT profile, conformance framework, catalogs, design system, offline tools, provenance, and validation evidence.

## Source profile

The uploaded corpus contains 10,000 records across 49 topics and six tiers. Its class distribution is 7,875 positive, 2,000 negative, and 125 certification records. The source attachment is preserved unchanged under `source/uploaded/`, and all wrapped documents are reconstructed under `source/reconstructed/`.

## Evidence boundary

No native JA Portal Scene compiler, renderer, physics engine, portal runtime, serializer, package host, or R12/MCRT executor was supplied. Compiler and runtime fields are modeled corpus evidence. Structural validation confirms package integrity and source fidelity; it does not claim native execution.
