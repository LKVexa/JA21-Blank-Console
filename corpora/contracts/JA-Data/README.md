# JA21 JA Data Language Suite 1.0.0

A standalone, air-gap-safe technical and educational publication for the JA21 JA Data Language profile.

## Primary products

- **Technical corpus:** 10,000 normalized records, 32 features, 10 levels, 10 validation classes.
- **Example pack:** 1,000 source-faithful `.jad` programs with complete catalogs.
- **Textbook:** 22 chapters and approximately 16,569 words.

## Publication layer

The suite adds a curriculum, workbook, instructor guide, grammar, language specification, compiler and runtime contracts, semantic operator registry, R12/MCRT evidence schema, conformance framework, starter project, architecture maps, publication system, offline tools, manifests, and validation report.

## Evidence status

The source corpus describes modeled compiler and runtime outcomes. No native JA Data parser, compiler, engine, distributed scheduler, certificate signer, or R12/MCRT runtime was included in the attachment. The release therefore preserves expectations and evidence identities without claiming native execution.
