# JA21 MCRT Portal Timeline Language Suite 1.0.0

A standalone research, teaching, implementation, and certification package for `mcrt.portal.timeline` 0.3.

## Core products

- 10,000-record normalized technical corpus
- 1,000 source-faithful `.mcrt` example programs
- 22-chapter technical textbook
- Twelve-week curriculum, workbook, and instructor guide
- Grammar, language profile, compiler/runtime contracts, semantic operators, R12/MCRT evidence profile, conformance cases, and certification guide
- Offline validators, catalogs, architecture maps, local publication system, manifests, and checksums

## Corpus profile

- Positive: 7,875
- Negative/diagnostic: 2,055
- Certification: 70
- Topics: 45
- Tiers: six

## Native execution boundary

The upload did not include a native MCRT Portal Timeline compiler or runtime. This release validates source hashes, structure, catalogs, manifests, and packaging. Compiler/runtime results in the corpus are modeled evidence until a native implementation appends observed receipts.
