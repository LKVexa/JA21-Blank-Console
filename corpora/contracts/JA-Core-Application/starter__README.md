# JA Core Starter Application

`main.ja` is a small corpus-derived starting point. Extend it into a package with one additional module, a structured error type, a capability-gated operation, and a deterministic test profile.

Required student outputs:
- source hash;
- module/package diagram;
- semantic and AST worksheet;
- R12 and MCRT draft;
- validation matrix;
- limitation statement.
