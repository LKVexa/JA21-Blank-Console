# JA21 JA Core Application Language Suite 1.0.0

> A standalone, air-gap-safe publication of the JA Core Application Language corpus.

## At a glance

| Asset | Quantity |
|---|---:|
| Technical corpus | 10,000 records |
| Source scripts | 1,000 `.ja` programs |
| Language features | 31 |
| Proficiency levels | 10 |
| Validation classes | 10 |
| Textbook chapters | 22 |
| Corpus shards | 20 |

## Primary deliverables

1. **Technical corpus** — normalized records with source, semantics, AST, compiler, runtime, validation, optimization, R12, MCRT, and coupling-mechanics evidence.
2. **1,000-script example pack** — exact source-faithful programs balanced across ten levels and proportionally across ten validation classes.
3. **Technical textbook** — 22 chapters covering application construction, language semantics, compiler/runtime architecture, evidence, certification, and a capstone.

## Additional deliverables

- feature atlas and architecture map;
- diagnostic and script catalogs;
- twelve-week curriculum, workbook, and instructor guide;
- provisional grammar and standalone specification;
- compiler and runtime contracts;
- semantic operator registry;
- R12/MCRT schema;
- conformance framework;
- starter project;
- publication design system and local SVG cover;
- offline inspection and validation tools;
- reconstructed source documents, manifests, and checksums.

## Trust statement

A native JA Core parser, compiler, VM, package manager, FFI host, or R12/MCRT runtime was not supplied. The suite preserves modeled expected outcomes and validates publication structure; it does not claim native execution.
