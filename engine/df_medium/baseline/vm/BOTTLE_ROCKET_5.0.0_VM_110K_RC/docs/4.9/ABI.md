# ABI Specification
ABI 1.0 is frozen: R0–R3 arguments, R0–R1 returns, R2–R7 scratch, R8–R15 preserved, 20 service IDs, 14 required production trap classes, and Device ABI 1.0 mediation. Guest pointers are never host pointers; all lengths, capabilities, quotas, and buffers are validated before host dispatch.
