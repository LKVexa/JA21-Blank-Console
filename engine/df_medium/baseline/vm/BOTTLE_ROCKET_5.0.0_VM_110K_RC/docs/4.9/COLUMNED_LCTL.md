# COLUMNED LCTL Profile
The frozen source profile is LCTLC/1.1. Executable rows use eight columns: ID | LANE | OP | OUT | CTRL | IN | ARG | META. Types, register bounds, memory bounds, CFG reachability, stack/call-stack consistency, declared execution bounds, and least-privilege capabilities are verified before BRIR/BRIM emission. LCTLC/1.0 is not silently reinterpreted.
