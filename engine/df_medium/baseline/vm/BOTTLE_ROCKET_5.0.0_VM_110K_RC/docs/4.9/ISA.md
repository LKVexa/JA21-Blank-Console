# ISA Specification
ISA 4.1 is frozen for the 4.9 RC: 32 opcodes, 16 logical 1,048,576-bit registers, four arithmetic modes (WRAP, CHECKED, SATURATE, TRAPPING), 4,096-byte guest memory, 256-entry wide stack, protected call stack, strict branch/shift/memory bounds, and typed traps. Numeric opcode meanings are unchanged from the 4.7 runtime contract.
