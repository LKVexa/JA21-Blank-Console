# BOTTLE ROCKET 5.0.0 operational gate

5.0.0 is a production-release qualification overlay over the frozen LCTLC/1.1 → BRIR/1.1 → BRIM/1+BRPV/1 → BRTM/1 execution contract. It does not silently change ISA 4.1, ABI 1.0, Device ABI 1.0, BRCR/1, BRGD/1, or core ABI `0x00040700`.

A 5.0.0 package may be labeled **OPERATIONAL** only when all 96 BR-500 atomic requirements have fresh evidence. Repository-local PASS results do not substitute for cross-platform execution, a literal 72-hour native soak, or genuinely independent rebuild/replay evidence.

The qualification candidate therefore carries both a local readiness result and a strict promotion result. Any unavailable external proof remains BLOCKED.
