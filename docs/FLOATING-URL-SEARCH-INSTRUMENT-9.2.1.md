# JA21 Floating URL/Search Instrument 9.2.1

The 9.2.1 shell converts the top command band from one large pill into a transparent layout carrier with three floating instruments. The centered URL/search pill is 46 DIPs tall, maximizes at 920 DIPs wide, uses a 23-DIP radius, a device-pixel hairline, low-energy shadow, one-line input, a blank-state watermark, and a progressively disclosed intent chip. Peripheral controls are deliberately smaller glass pills so navigation/search remains the visual center of gravity.

This change preserves the full-bleed content plane and composition-safe WebView2 overlay model. It does not alter VEC1 fabric-verdict semantics or portable workspace ownership.
