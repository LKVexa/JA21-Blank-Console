# Luxury omni experience specification

**8.0.3:** WPF host is the native **JA21 Omni Bin** window substitute. Details: `OMNI-BIN-WINDOW-8.0.3.md`.

The 7.0.0 shell implements the requested design system as functional UI behavior rather than ornament.

- **Ultrasmooth / zero-jitter:** event-driven motion only; layout rounding and device-pixel snapping; critically damped spring drawer.
- **Hairline-light:** 1-pixel low-alpha borders and separators with soft slate typography.
- **Glassmorphism / layered panels:** translucent command rail, tabs, status layers, document masthead and contextual drawer.
- **Ambient gradients:** quiet aqua/violet radial fields over a near-white canvas.
- **Whitespace dominant:** document and search content retain visual priority over controls.
- **Frictionless patterns:** predictive address intent, keyboard-first navigation, link re-entry through JA policy.
- **Progressive disclosure:** secondary runtime/helper controls live in the contextual drawer.
- **Cubic-bezier micro-motion:** hover/selection motion is short and semantically tied to interactability.
- **Subpixel smoothing:** Display text formatting, ClearType and pixel snapping.
- **Calm technology:** no continuous animation or noisy status feed.
- **Trust-forward:** document masthead exposes JA Mirror/script isolation state and security boundaries in neutral language.
- **Emotionally neutral microcopy:** routine failures describe the stage and recovery boundary without alarm language.

Core components: hairline input bar, floating action bubbles, pill controls/tabs, ghost buttons, layered panels, contextual drawer, and JA Mirror document surface.
