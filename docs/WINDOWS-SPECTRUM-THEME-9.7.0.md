# JA21 9.8.4 Windows Spectrum Theme

JA21 keeps the Copilot-like luminous/iridescent hierarchy but uses a Windows/Microsoft spectrum instead of the prior cyan-only accent.

Palette:
- Windows blue `#0078D4`
- cyan `#00B7C3`
- Windows green `#107C10`
- Windows gold `#FFB900`
- Windows red `#F25022`

The spectrum is deliberately constrained to the omni-box border/focus ring, Copilot button, bottom-island hairline, and low-opacity ambient blooms. Core surfaces remain neutral white/graphite for readability and a technical luxury appearance.
