# RC-PW Hosted Reference Resource Budgets

The qualifier measures CPU tick latency, process RSS, 1 MiB read/write latency, save size, backlog decisions, and degradation behavior on the executing host.

GPU is `NOT_APPLICABLE` for the deterministic SVG/headless reference renderer. This is not a GPU production benchmark. Canonical world behavior has no GPU dependency in this profile.

The deterministic resource governor protects canonical/persistence/ledger work before remote fidelity, speculative prewarm, and presentation quality.
