# QUORUM RC-PW 7.0.0 — Resource Governor

## Priority order

1. canonical integrity and mutation safety;
2. ledger durability / save recovery;
3. minimum causal simulation obligations;
4. interaction-critical materialization/physics/AI;
5. navigation/audio needed for active interaction;
6. remote simulation fidelity;
7. rendering quality;
8. speculative prewarm and cosmetic effects.

## Required budgets

Declare CPU time, GPU time where applicable, resident memory, transient memory, I/O bandwidth, storage growth, entity update quotas, materialization queue depth, ledger throughput, and checkpoint latency for every qualification profile.

Exhaustion must produce measurable staged degradation rather than silent state loss.
