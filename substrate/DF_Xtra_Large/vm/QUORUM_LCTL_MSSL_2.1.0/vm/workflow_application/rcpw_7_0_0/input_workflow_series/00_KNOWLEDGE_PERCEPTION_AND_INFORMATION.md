# QUORUM RC-PW 7.0.0 — Knowledge, Perception, and Information

Canonical truth and agent knowledge are different authorities.

For an agent/institution, track as applicable:
- directly perceived facts;
- communicated facts;
- rumor/hearsay;
- inferred beliefs;
- stale information;
- deliberately false information;
- confidence/source provenance;
- last update time/location.

Information propagation uses canonical travel/communication mechanisms and delay. NPCs do not become omniscient because a remote event exists in the global ledger.

Dialogue, law, social response, and narrative eligibility must query the appropriate knowledge view where world rules require it.
