# QUORUM RC-PW 7.0.0 — Settlement Growth and Infrastructure

Settlements are evolving canonical systems rather than static scenery.

Support:
- founding;
- zoning/land use where applicable;
- housing;
- workplaces/production;
- storage/markets;
- roads/trails/rail/bridges/ports;
- utilities/resources where applicable;
- jurisdictional expansion;
- population capacity;
- construction/repair/decay;
- abandonment/reclamation.

Infrastructure changes mutate canonical topology through validated transactions. Newly constructed routes and destroyed links immediately affect canonical travel/logistics after commit, regardless of visual fold distance.
