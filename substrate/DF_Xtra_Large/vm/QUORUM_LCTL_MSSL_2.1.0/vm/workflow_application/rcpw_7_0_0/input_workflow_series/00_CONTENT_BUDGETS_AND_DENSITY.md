# QUORUM RC-PW 7.0.0 — Content Budgets and Density

Define per-profile budgets for:
- persistent canonical entities;
- active high-fidelity agents;
- remote cohorts/strategic agents;
- settlements;
- interiors/portals;
- route graph nodes/edges;
- ecology cohorts;
- economic transactions;
- ledger events;
- materialization queue;
- visible landmarks;
- resident/transient memory;
- I/O and checkpoint throughput.

Qualification reports p50/p95/p99 latency, queue depth, high-water memory, storage growth, catch-up time, and degradation behavior.

Exceeding visual/content density budgets may reduce derived fidelity, not erase authoritative state.
