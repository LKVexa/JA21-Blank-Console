# QUORUM RC-PW 7.0.0 — World Topology and Portal Contract

Canonical topology is distinct from folded display geometry.

Model:
- regions and adjacency;
- roads, rail, waterways, bridges, tunnels, passes;
- building exteriors/interiors;
- doors, gates, elevators, ladders, caves, tunnels, fast-travel/teleport anchors;
- occlusion/visibility boundaries;
- jurisdiction and ownership boundaries.

A portal transition is a canonical topological transition with explicit source, destination, traversal constraints, occupancy/collision validation, and save/replay identity. Fold projection may compress the visual distance around portals but may not invent adjacency.

Provide topology property tests for reachability, one-way edges, blocked edges, disconnected components, nested interiors, cyclic routes, and repeated fold/unfold.
