# QUORUM RC-PW 7.0.0 — Master Execution Contract

## Non-negotiable rules
1. Implementation tasks modify/test the actual target repository; prose-only completion is invalid.
2. Baseline source/content/compiler/runtime/schema/policy/evidence are hashed before modification.
3. Canonical identity, topology, time, ownership, and causality outrank folding, LOD, AI, materialization, rendering, archives, and execution layout.
4. Established canonical history is not rewritten by world expansion, generation, archival, or rehydration.
5. Authored and generated content carry explicit provenance/version authority.
6. Undefined frontier is not interactable canonical geography.
7. Agent/institution knowledge is distinct from omniscient canonical truth.
8. Generational succession never recycles canonical identity.
9. Long-horizon abstraction declares validity/error and cannot bypass event barriers.
10. Archival compaction declares exact/aggregated/reconstructed/unavailable proof classes.
11. Rehydration cannot present reconstructed details as historically exact without evidence.
12. Partition/worker layout remains non-canonical and deterministic profiles compare across layouts.
13. Cross-partition mutation/ownership remains transactional and replayable.
14. Canonical randomness uses versioned deterministic streams.
15. Interaction targeting remains uniquely canonical through fold/expansion/archive state.
16. Resource exhaustion reduces derived fidelity before authoritative-state integrity.
17. Inherited PASS claims are rerun against current build/content.
18. Mock/stub/TODO/prewritten PASS evidence cannot satisfy operational gates.
19. Untrusted world packages/saves/patches/generated content are validated before canonical admission.
20. Save/replay captures all model/schema/era/generator/archive versions needed for interpretation.
21. Hot patch/migration/rollback remain barrier-controlled and tested.
22. Headless replay supports canonical historical verification.
23. Long-soak/generational claims require completed observed evidence.
24. Every release states QP/WQ/fabric/autonomous-world profile plus blockers and rollback status.

## Q0-Q36 workflow
- **Q0 Baseline capture** — hash/inventory all current authorities and evidence.
- **Q1 Atomic traceability** — requirement→contract→source→test→evidence→profile.
- **Q2 Canonical ontology/world model** — identities, types, topology, time, provenance.
- **Q3 Semantic world grammar** — compositional constraints and validation.
- **Q4 Frontier/world expansion design** — namespace, seeds, generation, admission transaction.
- **Q5 World compiler** — deterministic package build, DAG, provenance, manifests.
- **Q6 Runtime ABI/capabilities** — services, ownership, versions, mutation boundaries.
- **Q7 Fabric/partition design** — ownership, migration, transactions, recovery.
- **Q8 Causal concurrency/event barriers** — conflict semantics and ordering.
- **Q9 Fold/reference design** — transforms, horizon classes, inverse targeting, fallback.
- **Q10 Time/random/long-horizon design** — deterministic streams, eras, abstraction windows.
- **Q11 Knowledge/perception design** — observer-local facts, rumor, information propagation.
- **Q12 Generational/institution design** — lineage, roles, succession, inheritance.
- **Q13 Ecology/economy/settlement evolution design** — long-lived systems and conservation.
- **Q14 Archive/rehydration design** — proof boundaries, retained state, reconstruction provenance.
- **Q15 MSSL semantic authority** — contracts, invariants, failure states.
- **Q16 Columned LCTL implementation** — editable executable source.
- **Q17 Canonical LCTL lowering/verifier** — governing canonical execution verification.
- **Q18 World package compile/admission** — compile, validate, atomically admit.
- **Q19 Runtime boot/single-worker reference** — establish reference canonical behavior.
- **Q20 Multi-worker/fabric integration** — deterministic partitioned execution.
- **Q21 Positive/boundary tests** — nominal, extrema, fold, portal, frontier, archive boundaries.
- **Q22 Adversarial/failure tests** — malformed, stale, conflict, corrupt, interrupted, exhaustion.
- **Q23 Property/model tests** — identity, topology, targeting, history, conservation, recovery.
- **Q24 World-system tests** — routes, agents, economy, ecology, law, environment, events, transport.
- **Q25 Knowledge/narrative tests** — information delay, beliefs, reservations, historical hooks.
- **Q26 Generational/era tests** — succession, inheritance, role continuity, long-age evolution.
- **Q27 Archive/rehydration tests** — compaction, protected obligations, provenance, reconstruction.
- **Q28 Determinism/replay** — repeated seeded canonical checkpoint/ledger digests.
- **Q29 Autonomous-world conformance** — player-near/absent, fine/coarse, archive/resident comparisons.
- **Q30 Multi-worker conformance** — worker layouts, repartition, recovery equivalence.
- **Q31 Persistence/migration/rollback** — old saves, expanded worlds, schema/model/archive versions.
- **Q32 Performance/content-scale** — percentiles, queues, memory/I/O/storage, generation/rehydration cost.
- **Q33 Golden World suite** — applicable GW-01 through GW-80.
- **Q34 Multi-era soak/chaos** — expansion, succession, archive, faults, patches, recovery.
- **Q35 Headless/independent historical replay** — reproduce canonical history/evidence.
- **Q36 Promotion** — QP/WQ/fabric/autonomous profile, blocker/risk closure, rollback proof.

## Status vocabulary

## Gate vocabulary

The prompt/workflow defines qualification requirements. It does not itself prove a runtime/world implementation operational.
