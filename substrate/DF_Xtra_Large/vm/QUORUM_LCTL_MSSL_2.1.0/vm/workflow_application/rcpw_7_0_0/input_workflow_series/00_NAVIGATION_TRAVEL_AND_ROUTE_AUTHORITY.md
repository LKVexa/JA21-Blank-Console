# QUORUM RC-PW 7.0.0 — Navigation, Travel, and Route Authority

Canonical travel occurs on canonical topology, never folded display distance.

Support:
- walk/ride/vehicle/rail/water/air-equivalent route classes where implemented;
- roads/trails/bridges/tunnels/portals/interiors;
- dynamic blockages;
- route costs and travel time;
- agent/transport route progress;
- path replan;
- region crossing;
- reservation/capacity where needed.

Remote agents may advance along abstract route segments, but elapsed canonical distance/time must remain consistent with local materialization.

Fold projection is permitted to compress appearance only.
