# QUORUM RC-PW 7.0.0 — World Expansion and Frontier Synthesis

World expansion is a canonical transaction, not a render trick.

## Expansion pipeline
1. reserve canonical namespace/coordinate extent;
2. choose/derive deterministic seed;
3. apply semantic world grammar;
4. synthesize candidate terrain/topology/biome/content;
5. validate route/portal/topology closure;
6. allocate stable identities;
7. validate content/resource budgets;
8. generate provenance/dependency manifests;
9. run deterministic reference tests;
10. atomically admit the new region to canonical world state.

Undefined frontier remains explicitly undefined. The renderer may depict atmospheric horizon/unknown-space presentation, but cannot expose unvalidated frontier as interactable canonical geography.
