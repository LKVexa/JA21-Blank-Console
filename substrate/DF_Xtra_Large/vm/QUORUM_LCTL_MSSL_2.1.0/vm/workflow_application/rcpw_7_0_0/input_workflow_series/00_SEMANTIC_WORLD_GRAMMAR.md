# QUORUM RC-PW 7.0.0 — Semantic World Grammar

Define a machine-checkable grammar for composing canonical world content.

A world grammar may describe:
- region type and adjacency;
- biome/habitat constraints;
- terrain/water relationships;
- settlement suitability;
- infrastructure/route rules;
- jurisdiction/institution rules;
- population/ecology capacity;
- resource/production dependencies;
- portal/interior composition;
- landmark constraints;
- narrative/event anchors.

Generated content must satisfy grammar constraints before canonical admission. The grammar is versioned, testable, and separate from visual style.

Provide positive and negative generation fixtures, ambiguity detection, dependency validation, and semantic digest output.
