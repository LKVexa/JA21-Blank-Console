# QUORUM RC-PW 7.0.0 — Behavior, Goals, and Social AI

Persistent agents own canonical goal/schedule/social state independent of animation/rendering.

Define:
- goals and priorities;
- schedules;
- needs/resources;
- occupations;
- household/group relationships;
- factions/reputation;
- perception/memory abstractions;
- interaction reservations;
- law/social response;
- off-screen decision fidelity.

High-detail behavior may collapse to strategic/route/schedule simulation remotely, but committed outcomes and unresolved obligations must survive promotion/demotion.

Agent AI cannot directly rewrite canonical facts it does not own; it must request mutations through the runtime ABI.
