# QUORUM RC-PW 7.0.0 — Agent Life Simulation Contract

Agents remain persistent across fidelity levels.

Each persistent agent may carry:
- identity and lineage;
- canonical location/route;
- health/injury/death;
- inventory/equipment;
- needs/resources;
- schedule;
- occupation;
- household/group;
- faction/reputation;
- goals/intent;
- relationships;
- memory/history anchors;
- unresolved obligations;
- narrative significance.

Local high-fidelity AI and remote abstract simulation must reconcile elapsed canonical time. Off-screen resolution must state whether it was exact, abstract, deferred, or blocked.

No agent may be recreated from a generic spawn template if a persistent canonical identity already owns that role/state.
