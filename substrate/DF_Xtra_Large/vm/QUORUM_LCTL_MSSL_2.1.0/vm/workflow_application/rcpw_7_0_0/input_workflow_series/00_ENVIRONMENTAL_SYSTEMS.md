# QUORUM RC-PW 7.0.0 — Environmental Systems Contract

Coordinate world-scale environment state across:
- day/night and calendar;
- weather fronts;
- temperature;
- precipitation;
- wind;
- fog/cloud/smoke;
- water/hydrology;
- vegetation/resources;
- fire/spread;
- snow/mud/wetness where implemented;
- acoustic/visibility conditions.

Environmental propagation uses canonical geography and time. Folded visual distance must not cause storms, fires, floods, sound, or seasonal effects to propagate faster than the qualified canonical model.

Remote environment simulation may reduce spatial resolution but must preserve causal continuity and deterministic replay inputs.
