# QUORUM RC-PW 7.0.0 — Climate, Seasons, and Ecological Succession

Separate short-term weather from long-term environmental evolution.

Model where appropriate:
- seasons/calendar;
- climate regime parameters;
- precipitation/temperature trends;
- hydrology;
- vegetation succession;
- soil/resource depletion/recovery;
- fire history;
- habitat change;
- species migration;
- settlement/infrastructure pressure.

Long-horizon environmental state must remain causally linked to canonical geography and world age. Archival summaries preserve conserved quantities and significant disturbances needed for later rehydration.
