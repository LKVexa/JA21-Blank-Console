# QUORUM RC-PW 7.0.0 — Archival Compaction and Causal Rehydration

Archival is an extreme representation reduction, not deletion of the world.

## Archive must retain
- canonical identities required by history/obligations;
- region/topology identity;
- conserved ecological/economic/demographic state;
- institutional/ownership state;
- unresolved obligations/event reservations;
- compact causal proofs;
- provenance and versions;
- rehydration seed/model metadata;
- last exact/checkpoint digests.

## Rehydration
Rehydration rebuilds richer simulation/presentation from archived authority. Reconstructed microdetails are labeled reconstructed/inferred unless exact evidence exists.

Archive policies are versioned, reversible within declared proof limits, and forbidden from discarding information required for active canonical obligations.
