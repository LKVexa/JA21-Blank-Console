# QUORUM RC-PW 7.0.0 — Asset Virtualization and Residency

Separate canonical semantic residency from derived asset residency.

Asset tiers may include:
- canonical semantic metadata;
- collision/navigation data;
- interaction-critical assets;
- visual geometry/materials/textures;
- animation/audio;
- speculative prewarm;
- cold archival assets.

Eviction may remove reconstructible derived assets, not the sole authoritative state or unresolved event obligations.

Measure residency, cache hit/miss, I/O latency, decompression/compile latency, prewarm backlog, eviction churn, and recovery after overload.
