# QUORUM RC-PW 7.0.0 — Combat, Damage, and Physics Causality

Combat and destructive physics are event-barrier systems.

Canonical facts include:
- participants;
- health/damage/injury;
- ammunition/inventory consumption;
- projectile or abstract attack result;
- destruction state;
- ownership/crime/law consequences;
- death/incapacitation;
- causal event history.

Remote combat may be fully simulated, abstractly resolved, or deferred only through a qualified model that records its fidelity/model version and deterministic inputs.

Fold geometry may never cause target aliasing, impossible projectile shortcuts, or destruction of the wrong canonical entity.
