# QUORUM RC-PW 7.0.0 — Autonomous World Conformance

Compare autonomous world evolution across:
- different worker layouts;
- different shell/fold histories;
- player absent versus nearby where no interaction occurs;
- archive versus continuously resident reference regions;
- short-step versus long-horizon abstraction;
- save/reload and migration;
- world expansion before/after selected historical checkpoints.

Required equivalence focuses on canonical semantics, conserved quantities, causal obligations, and declared stochastic tolerances—not identical cosmetic reconstruction.

Emit divergence reports with the first canonical checkpoint/event where equivalence breaks.
