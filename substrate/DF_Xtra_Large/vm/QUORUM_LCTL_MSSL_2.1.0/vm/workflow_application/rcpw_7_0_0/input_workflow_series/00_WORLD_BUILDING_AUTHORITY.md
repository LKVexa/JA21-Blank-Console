# QUORUM RC-PW 7.0.0 — World Building Authority

## Mission
Define a world as a canonical, persistent, causally evolving semantic graph whose highest-fidelity 3D presentation is only one embodiment.

## Required canonical layers
- world/continent/region/subregion graph;
- terrain and elevation authority;
- biome/habitat authority;
- waterways and hydrology;
- roads/rail/trails/transport graph;
- settlements and jurisdiction;
- structures, interiors, portals, and ownership;
- resources and production sites;
- ecology and population;
- economy and logistics;
- factions, law, reputation, and social state;
- weather/environment;
- narrative/event anchors;
- historical/causal ledger.

Every authored or generated object must have stable identity, provenance, version, canonical location/topology, and lifecycle.

## World-building rule
Visual folding must never shorten canonical travel time, join regions that are not canonically adjacent, merge distinct interiors, duplicate landmarks, or alter ownership/jurisdiction.
