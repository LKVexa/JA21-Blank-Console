# QUORUM RC-PW 7.0.0 — Production Capacity Planning

Define capacity envelopes by qualification profile.

Measure:
- canonical entities;
- active high-fidelity entities;
- remote agents/cohorts;
- transactions/tick;
- durable events/second;
- checkpoint bytes/time;
- partition migration rate;
- materializations/second;
- asset I/O throughput;
- CPU/GPU/memory;
- queue depth;
- recovery time;
- storage growth/day-equivalent;
- p50/p95/p99 latency.

Capacity tests identify knee points and overload recovery. Scaling claims require observed evidence, not extrapolation alone.
