# QUORUM RC-PW 7.0.0 — Release Acceptance

## Qualification dimensions
Retain QP0–QP4 execution profiles and add world-quality profiles:

- **WQ0 — Structural:** valid topology, schemas, identities, seeds, and canonical content.
- **WQ1 — Local Continuity:** seamless local interaction, portal/interior, animation, physics, and reference rebasing.
- **WQ2 — Regional Persistence:** remote ecology/economy/agents/events evolve and rehydrate coherently.
- **WQ3 — Full-World Fold Continuity:** fold/unfold, horizon, fast traversal, multi-well, save/replay, and long-distance history pass.
- **WQ4 — Production World:** content-scale soak, recovery, resource budgets, risk closure, reproducible release, and profile-qualified evidence pass.

A release must state both an execution qualification profile (QP0–QP4) and a world-quality profile (WQ0–WQ4).

## Final acceptance bundle
- source/build manifest;
- requirements catalog;
- qualification matrix;
- world-quality matrix;
- Golden World reports;
- deterministic replay digests;
- resource/soak reports;
- crash/recovery report;
- compatibility matrix;
- risk register with disposition;
- rollback test report;
- SHA-256 evidence manifest.

# 5.0 operational extension

For WQ4 production-world promotion, the release must additionally include a reproducible world package build, runtime ABI compatibility report, deterministic-random stream registry, content-scale benchmark, headless replay digests, long-soak/chaos report, and migration/rollback proof.

Golden World qualification now covers GW-01 through GW-40.
