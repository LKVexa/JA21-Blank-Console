# QUORUM RC-PW 7.0.0 — Emergent Event Synthesis

Generate optional/emergent world events from canonical conditions rather than arbitrary narrative demand.

An event candidate declares:
- triggering facts;
- participant eligibility;
- knowledge requirements;
- location/topology constraints;
- resource requirements;
- exclusivity/reservations;
- fidelity requirement;
- duration/expiry;
- possible resolution models;
- durable consequences.

Candidate generation is deterministic or records sufficient provenance/seed state. Canonical admission occurs only after conflict, reservation, topology, and causality validation.

The generator may propose events; it does not own canonical outcomes.
