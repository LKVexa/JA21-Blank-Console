# QUORUM RC-PW 7.0.0 — Culture, Law, and Institutions

Model persistent institutions independently from individual occupants.

Possible institution state:
- jurisdiction;
- membership/leadership;
- rules/laws;
- reputation/legitimacy;
- treasury/assets;
- obligations/contracts;
- enforcement capacity;
- alliances/conflicts;
- historical events;
- succession process.

Law/social consequences depend on canonical events plus who plausibly knows those events. Institutional changes are causal world events, not hidden content swaps.

Qualification covers succession, jurisdiction change, delayed information, policy change, archive/rehydration, and long-lived obligations.
